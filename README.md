## ✨ Features That Stand Out

🚀 **Real-Time Online Multiplayer**  
Instantly create public or private rooms. Share your room code and invite friends from anywhere in the world. Built on lightning-fast Socket.io technology for zero-lag card slinging.

📱 **Mobile-First Vertical Design**  
No more awkward landscape screen rotations! Designed specifically for one-handed portrait mode play. Perfect for gaming on the go.

🤖 **Smart Drop-In AI Bots**  
Waiting for a friend? Someone disconnected? Our intelligent AI bots seamlessly take over so the game never stops. Play solo offline against up to 3 bots to sharpen your skills.

🎨 **Customizable Gameplay**  
Your game, your rules! Customize the number of players, point limits, and special action cards before you start.

## 🎮 How to Play

1. **Match & Play**: Match cards by color or number to the top card of the discard pile.
2. **Action Cards**: Use Skips, Reverses, and Draw Twos to sabotage your opponents.
3. **Go Wild**: Drop Wild and Wild Draw Four cards to completely change the active color.
4. **Call It**: Don't forget to press the "Call" button when you're down to your last card, or face a 2-card penalty!
5. **Win**: Be the first to empty your hand to win the round and score points.

## 🛠️ Tech Stack

Uno Vertical is engineered for performance and compatibility across all modern devices:

* **Frontend**: HTML5 Canvas, CreateJS / EaselJS, Tailwind CSS
* **Backend**: Node.js, Express
* **Real-Time Communication**: Socket.io
* **Build Tool**: Vite

## 🚀 Quick Start (Local Development)

Want to run your own server or contribute? It's incredibly easy to get started!

### Prerequisites
* Node.js (v16 or higher)
* npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HYPER12755/uno-vertical.git
   cd uno-vertical
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the backend multiplayer server:**
   ```bash
   npm run start:server
   ```

4. **Start the frontend development server (in a new terminal):**
   ```bash
   npm run dev
   ```

5. **Play!**
   Open your browser and navigate to `http://localhost:3000`
